## Running This Site Locally

### Prerequisites
- Node.js 18 or higher
- npm

### Setup

```bash
git clone https://github.com/aryan/portfolio.git
cd portfolio
npm install
npm run dev
```

The site will be running at `http://localhost:3000`.

### Build

```bash
npm run build
npm start
```
